# ☕ بوت طلبات كافيه
### ثناء | thanaa.codes

بوت يستقبل طلبات القهوة من الزباين، يختارون نوع القهوة والحجم والحلا، ويحسب لهم الاجمالي تلقائياً.

## ✨ وش يسوي؟
- يعرض 6 انواع قهوة: عربية، اسبريسو، كابتشينو، لاتيه، موكا، مثلجة
- يخلي الزبون يختار الحجم: صغير، وسط، كبير
- يضيف حلا: كوكيز، كيك عسل، تشيز كيك
- يحسب الاجمالي حسب العدد والحجم
- يستلم اسم الزبون ورقم جواله

## 🚀 كيف تشغليه؟
python coffee-shop-order-bot.py

## 💰 السعر
2000 ريال سعودي - نسخة كاملة للكافيهات

الطلب: لاتيه
الحجم: كبير
الحلا: كوكيز
العدد: 2
الاجمالي: 82 ريال
